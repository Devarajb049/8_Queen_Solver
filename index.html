3. Core Concepts & A* Formula

Theoretical foundations
Theory
A* Evaluation Function
f(n) = g(n) + h(n)
f(n) Total estimated cost of path through state n
g(n) Actual moves taken from start state to state n
h(n) Estimated remaining moves from state n to goal
Heuristic Value (h): Estimated remaining cost to reach the goal state.
Actual Moves (g): Number of moves actually taken to reach the goal state.
Nodes Explored: Number of puzzle states expanded by the algorithm.
Execution Time: Time taken by the algorithm to find the solution.
⚠️ Important Distinction:

Never confuse heuristic values (3, 4, 6) with actual solution moves (16). The heuristic value h(n) is an initial lower-bound estimate computed before or during search (h ≤ g*). The actual moves (16) represent the true minimal path length (g) discovered once A* reaches the goal state.
